# Enterprise Library Management System

## Introduction

The Enterprise Library Management System is a premium desktop application developed using C#, .NET 8, SQL Server, and WinForms. The system helps manage books, members, loans, returns, and reports efficiently.

## Objectives

- Manage library books efficiently
- Maintain member records
- Handle issue and return operations
- Generate reports and analytics
- Provide secure authentication system

## Technologies Used

- C#
- .NET 8
- WinForms
- SQL Server
- Dapper
- Guna UI2

## Features

- Authentication & Login
- Book Management
- Member Management
- Loan & Return System
- Reports & Analytics
- Dashboard
- Export Features

## System Architecture

The project follows layered architecture:
- Core Layer
- Data Layer
- Service Layer
- UI Layer

## Conclusion

The system successfully manages library operations with a modern premium interface and enterprise-level architecture.
